# Работа 2. RL в последовательных рекомендациях

**Статья:** [article.pdf](article.pdf), 5 страниц. **Код и результаты:** [code/](code/).

Итоговая статья объединяет оба исследовательских цикла: обучение GPT-2
над идентификаторами треков, reward model, пятишаговый REINFORCE,
затем усиление RM и проверку copy-адаптера с совместным CE+reward.

## Основной результат

- В первом цикле RL увеличивал прогноз награды, но не подтвердил улучшения
  NDCG. Штраф за вымышленную историю не превзошёл ансамблевую награду.
- На новой когорте baseline с copy-адаптером и CE повысил NDCG@10 на 28,5%
  относительно frozen GPT-2; 95% CI абсолютного прироста [0,001290; 0,004613].
- На тех же новых запросах MSE RM снизилась с 0,184392 до 0,059784.
  Добавление reward по согласию RM немного ухудшило NDCG против matched CE:
  −0,000096, 95% CI [−0,000162; −0,000037].

Положительный эффект supervised baseline отделён от эффекта RL.
Превосходство над repeat не установлено. Новая когорта — другие UID того же
периода Yambda, не независимая будущая неделя. Proxy reward не выдаётся
за измеренные удовлетворённость, время после интервенции или retention.

## Как проверить

Из этой папки выполните:

```powershell
cd code
uv sync --locked --extra dev --python 3.11.9
uv run --locked python scripts/verify_submission.py
uv run --locked pytest -q
```

Без Yambda/GPU пересчитываются оба цикла: 27 и 24 массива прогнозов,
ranking-метрики, user-cluster интервалы, RM errors и rollout checks.
Тест, подменяющий NDCG при обновлённом checksum, должен завершиться отказом.
Нейронные unit tests требуют extra `neural`; core-проверка обходится без него.

Исторические статьи каждого цикла сохранены внутри `code/paper/` и
`code/output/pdf/` для аудита. Главный файл для сдачи — один `article.pdf` в корне.
Из прежних исследований включены только UID manifests v3/v4, необходимые
для проверки отсутствия пересечений; результаты первой работы сюда не включены.
Общая библиотека `src/rec` сохранена целиком для совместимости окружения.
Сырые Parquet и веса не включены. [Полное воспроизведение](code/REPRODUCE.md).

Сборка статьи: из `code/` запустите
`uv run --locked python scripts/build_article.py` с установленным XeLaTeX.
Получится `article-rebuilt.pdf`; исходный файл для сдачи не перезаписывается.
