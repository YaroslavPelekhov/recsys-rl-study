# LaTeX: исследование RL-донастройки GPT-2

Основной файл — `article.tex`, движок **XeLaTeX**. В Overleaf выберите его как main document и XeLaTeX как compiler. Пакет содержит `numbers.tex` и векторные PDF figures; BibTeX не требуется, литература находится в статье.

Четыре страницы: данные и модель; rewards/REINFORCE и результаты; полное сравнение; RM/rollout audit и ограничения. Здесь нет вымышленных положительных результатов: основная гипотеза не подтверждена.

Текст редактируется вручную. Численные команды и графики обновляет `scripts/publish_task2.py` из компактных evidence. Графики PNG для просмотра и SVG для редактирования находятся в исходном репозитории. Основные значения проверяются `scripts/verify_task2.py`.
